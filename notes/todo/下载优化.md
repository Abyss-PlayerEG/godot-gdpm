# 下载优化

## 目标

优化插件下载速度，支持并行下载和分片下载。

> **进度 (2026-11-07)**：分片下载工具方法已落地并接入 `gdpm godot install` —
> `utils/download.py::download_file_chunked`（HEAD 探测 + 固定 4 片 Range 并行 +
> 不支持时回退单流，含端到端测试）。原单流 `download_file` 保留不变。
> 仍待做：接入阈值配置（chunked_threshold），`add`/`sync`/`import` 调用方接入，
> SHA256 校验待 P0-2 端点修复后启用。

## 当前状态

```
gdpm add: 单插件，单线程下载
gdpm sync: 多插件并行下载（最多 5 个）✅
```

## 目标状态

```
gdpm add: 单插件，超过 100MB 自动分片下载（5 片）
gdpm sync: 多插件并行下载（最多 5 个），超过 100MB 自动分片
```

## 实现方案

### 并行下载（gdpm sync）✅

已实现于 `src/gdpm/cli/sync.py`，**并发数由全局配置 `parallel_downloads` 控制**（2026-11 接线，默认 4）：

```python
parallel = read_global_config().parallel_downloads
semaphore = asyncio.Semaphore(parallel)
```

- 使用 `asyncio.Semaphore` 限制并发数
- 显示每个插件的独立进度条
- 单个失败不影响其他插件
- 同一配置同时控制 `gdpm godot install` 的分片数（进度条 Slice i/n 联动）

## 配置项

```toml
# ~/.gdpm/config.toml (全局配置, gdpm config set 管理)
[defaults]
parallel_downloads = 4          # 并行下载数: sync 多插件并发 + godot install 分片数 (已接线)

# 以下为计划项, 尚未实现:
# chunked_threshold = "100MB"   # 分片下载阈值 (add/sync 单文件超阈值自动分片)
```

> `chunk_count` 配置项已取消：分片数由 `parallel_downloads` 统一控制
> （`download_file_chunked(workers=...)`），不再单独设置。

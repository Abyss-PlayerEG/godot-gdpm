# 下载优化

## 目标

优化插件下载速度，支持并行下载和分片下载。

> **进度 (2026-11-07)**：分片下载工具方法已落地并接入 `gdpm godot install` —

> 仍待做：接入阈值配置（chunked_threshold），`add`/`sync`/`import` 调用方接入，
> SHA256 校验待 P0-2 端点修复后启用。

## 当前状态

```
gdpm add: 单插件，单线程下载
gdpm sync: 多插件并行下载（最多 5 个）✅
```

## 目标状态

```
gdpm add: 单插件，超过 100MB 自动分片下载（5 片）
gdpm sync: 多插件并行下载（最多 5 个），超过 100MB 自动分片
```

## 实现方案

### 并行下载（gdpm sync）✅

已实现于 `src/gdpm/cli/sync.py`：

```python
MAX_PARALLEL = 5
semaphore = asyncio.Semaphore(MAX_PARALLEL)
```

- 使用 `asyncio.Semaphore` 限制并发数
- 显示每个插件的独立进度条
- 单个失败不影响其他插件

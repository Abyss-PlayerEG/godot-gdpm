# 帮助系统重构与多语言（help i18n）

> 来源：2026-11-07 方案讨论定稿。**状态：待评审，评审通过后实施。**
> 结论先行：采用方案 B（提取纯函数渲染器 + 数据驱动），帮助文案全面 i18n（默认英文，配置可切换）。

## 一、背景与动机（现状体检，数据实测）

| 问题 | 实测数据 |
|------|---------|
| `app.py` 是四合一上帝文件 | 617 行 = 命令注册 + **323 行帮助渲染（52%）** + 横幅数据 + 输出回调 |
| 三套手写渲染器 | `GdpmCommand.format_help` / `_format_main_help` / `_format_group_help`——同样的 Usage/表格拼装散落三处，**修 bug 要修三处**（上次 `--show_all` 误显示为 Python 变量名的 bug 就案发于此） |
| 双份事实源且已漂移 | `COMMANDS` 字典（英文，主帮助用）vs 各命令 docstring（中文，子帮助用）——`"Initialize a new gdpm project"` vs `"初始化新的 gdpm 项目."`，加命令要改两个文件 |
| help 零测试 | 上次 Usage bug 靠人工发现，渲染逻辑无任何自动化保护 |
| 输出回调混杂 | `print_info` / `print_version` / `print_completion` 与渲染逻辑纠缠 |

## 二、决策记录（已讨论定案）

| 决策点 | 结论 |
|--------|------|
| 方案选择 | **B：提取纯函数渲染器 + 数据驱动**。否决 A（仅搬家，痛点全留）；否决 C（rich-click：新依赖 + Examples 面板是签名特性、不受库支持） |
| 默认语言 | **英文**，`~/.gdpm/config.toml` 配置切换，**必须方便后期扩展语言** |
| 词典本期覆盖 | **命令描述 + 分类名 + 示例标签**（76 条 `examples=` 声明的标签全部入词典） |
| 子命令帮助 | 标题与描述**跟随语言配置**（避免主帮助中文、子帮助英文的半吊子状态） |
| `print_*` 三个输出回调 | **留在 app.py**，本次只重构 help 渲染 |
| docstring 角色 | 降级为 **IDE 悬浮文档专用**，不再参与 help 渲染（消除中英漂移根源） |

## 三、架构设计

### 模块结构

```
src/gdpm/cli/
├── app.py     ← 瘦身目标: 仅命令注册 + category 挂载 + print_* 回调 (≤250 行, 现 617)
├── i18n.py    ← 新: 词条词典 + t() 回退链 + 语言配置读取
└── help.py    ← 新: 纯函数构建器 + Rich 渲染 + BANNER
```

### i18n 词典（唯一事实源）

```python
_COMMANDS: dict[str, dict[str, str]]        # 键 = 命令名 (稳定)
    {"init": {"en": "Initialize...", "zh": "初始化新的 gdpm 项目"}}
_CATEGORIES: dict[str, dict[str, str]]      # 分类名
    {"project": {"en": "Project", "zh": "项目"}}
_EXAMPLE_LABELS: dict[str, dict[str, str]]  # 键 = 英文原文 (英文为源)
    {"List installed versions": {"zh": "列出已安装版本"}}
```

- **回退链**：`目标语言 → en → 键名`（缺词条响亮暴露，不静默）
- **加语言 = 往词典补 `"ja"` 键**，未翻译条目自动回退英文——满足"方便后期添加"
- 命令侧保持 `examples=[("gdpm init", "Interactive create"), ...]` 英文原文不动，渲染时查词典取译文

### 语言配置

```toml
# ~/.gdpm/config.toml 新增段 (复用 global_config 基础设施)
[ui]
language = "en"        # 默认英文
```

优先级：`GDPM_LANG` 环境变量 > 配置文件 > 默认 `en`（环境变量便于临时切换/CI）。

作用范围：主帮助、组帮助、**子命令帮助的标题与描述**。

### 渲染器（help.py：先测后码）

| 纯函数（全部配单测） | 职责 |
|---|---|
| `build_usage(ctx)` | Usage 拼装——**上次 bug 案发地**，固化语义：真实选项拼写、Choice 展开 `stable\|rc\|...`、可选参数 `[name]`、`command_path` 补组名 |
| `build_option_rows(params)` | 选项表格行 |
| `build_example_rows(examples, lang)` | 示例行（英文标签查词典换语言） |
| `build_command_groups(commands, lang)` | 按 `category` 自动分组——**删除 COMMANDS 字典** |

| 渲染函数（薄壳，只管交给 Rich 画） |
|---|
| `render_main_help` / `render_group_help` / `render_leaf_help` |

命令侧唯一改动：`@click.command(cls=GdpmCommand, category="Project")`。

## 五、风险与对策

| 风险 | 对策 |
|------|------|
| `category=` 自定义 kwargs 与 click 机制冲突 | Phase 3 第一步做最小可运行验证，不行则退化为"app.py 挂载时手动 `cmd.category = ...`"（零侵入 click） |
| 词条迁移遗漏/键名打错 | `t()` 缺词条返回键名（响亮失败）+ Phase 4 语言冒烟覆盖 |
| docstring 不再驱动 help，IDE 悬浮与命令帮助内容可能不一致 | 接受——docstring 定位改为 IDE 专用；帮助的唯一事实源是词典 |
| 渲染行为回归 | Phase 2 单测固化全部已修语义；Phase 4 CliRunner 快照式断言 |

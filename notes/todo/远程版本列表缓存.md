# 远程版本列表缓存

> 来源：2026-11-18 用户提议。**状态：设计已定，待实现。**
> 目标：`gdpm godot list -r` 不再每次请求镜像，结果缓存到统一 cache 目录，带过期时间与离线降级。

## 一、现状

```
gdpm godot list -r
  → _list_remote()                          # list.py:311
  → fetch_remote_versions()                 # common.py:322 —— 每次必发 HTTP
  → httpx.get(f"{GODOT_DOWNLOAD_MIRROR}/versions.json", timeout=10)
  → parse_versions_json(resp.json())
```

- **唯一调用点**：`godot list -r`（`tests/test_remote_versions.py` mock 的也是这个函数）
- 统一缓存目录：`read_global_config().cache_dir`，默认 `~/.gdpm/cache/`，目前只有 `downloads/`（插件 zip）
- 现有 `FileCache` / `CacheProtocol` 是**按键拷贝 zip 文件**的接口（`get(key) -> Path`），不适合"单个 JSON + 元数据"形态，不复用

## 二、设计

### 1. 缓存文件位置

```
~/.gdpm/cache/metadata/godot_versions.json
```

新建 `metadata/` 子目录存放小型 JSON 文档，与 `downloads/`（大文件 zip）分离。
**零改动兼容现有命令**：

- `gdpm cache size` — `FileCache.size()` 是 `rglob` 整个 cache_dir，自动计入 ✓
- `gdpm cache clean` — `clean()` 是 `rmtree(cache_dir)` 整体重建，自动清掉 ✓

### 2. 文件结构（单文件字段）

```json
{
  "fetched_at": "2026-11-18T09:30:00+00:00",
  "url": "https://godot-download.playereg.top/versions.json",
  "body": [ { "name": "4.8", "releases": [...] }, ... ]
}
```

| 字段 | 说明 |
|------|------|
| `fetched_at` | 抓取时间，ISO 8601 UTC（`datetime.now(UTC)` 直接序列化，便于比较 TTL） |
| `body` | **原始响应原样存**（不存解析后的 `RemoteRelease`）——镜像 schema 变更不夹带旧解析逻辑，断网可原路重放 |
| `url` | 缓存有效性绑定端点：将来改 `GODOT_DOWNLOAD_MIRROR` 时旧缓存自动作废，无需手动清 |

### 3. 读写流程

```
get_remote_versions(refresh=False)
  ├─ 读缓存 (文件不存在/损坏/JSON非法 → 视为 miss)
  ├─ url 与当前常量不一致 → miss
  ├─ now - fetched_at < TTL → 直接 parse 返回（零网络请求）
  └─ 过期或 miss → 尝试网络
       ├─ 成功 → 写缓存(临时文件 + rename 原子写) → 返回
       └─ 失败 → 有过期缓存？
            ├─ 有 → 警告 "using stale cache (fetched_at=...)" → 返回旧数据   ← 离线韧性
            └─ 无 → 抛异常（维持现有错误提示）
```

**收益**：断网时 `list -r` 仍能列出版本（提示数据可能过期），当前是直接报错。

### 4. 代码组织（关键决策：分层，不改 fetch 语义）

| 函数 | 职责 | 归属 |
|------|------|------|
| `fetch_remote_versions()` | 纯网络抓取，**保持原样** | `godot/common.py`（现有） |
| `get_remote_versions(refresh=False)` | 新增：缓存读写 + TTL + 降级，内部调前者 | `godot/common.py`（新） |
| `_list_remote()` | 改为调 `get_remote_versions()` | `godot/list.py`（1 行改动） |

**原因**：现有 `test_fetch_uses_mirror_endpoint` 断言 `calls == [url]`、
`test_fetch_raises_on_failure` 断言抛异常——若把缓存塞进 `fetch_remote_versions`，
这两个测试会因 HOME 下真实缓存随机失败。分层后**旧测试一行不改**，缓存逻辑单独测。

### 5. TTL 与刷新

- `VERSIONS_CACHE_TTL_SECONDS = 86400`（24h）放 `constants.py`——Godot 几周才发一版
- 可选：`gdpm godot list -r --refresh` 强制绕过缓存（约 3 行）

## 三、测试计划

- [ ] 缓存 miss → 发请求 → 落盘（断言 `fetched_at`/`body`/`url` 结构）
- [ ] 缓存 fresh → 不发请求（断言 `httpx.get` 未被调用）
- [ ] 缓存过期 + 网络失败 → 返回旧数据 + 警告
- [ ] 缓存过期 + 网络成功 → 覆盖写入
- [ ] 缓存损坏（垃圾字节）→ 视为 miss 走网络
- [ ] `url` 不匹配当前镜像 → miss
- [ ] 测试用 `tmp_path` 注入缓存路径，不碰真实 HOME

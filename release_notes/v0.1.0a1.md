# v0.1.0a1

> First alpha of 0.1.0 — covers everything since **v0.0.6** (385 commits).
> Labeled **alpha** because a package manager's core is not finished yet:
> the dependency resolver is still a stub (no transitive resolution, no
> cycle detection), so this is not a feature freeze.

## English

### New Features

- **Mirror-only download channel** — Engine binaries and `versions.json` now come exclusively from the self-hosted mirror; official API URLs are gone from the client. A pure-GitHub worker resolves releases with direct asset probes and diagnostics, so downloads no longer depend on GitHub's API rate limits.
- **Godot Engine Management** — Install, uninstall, and switch Godot engine versions directly from CLI.
  - `gdpm godot install <version>` — Download and install (supports `--csharp` / `-cs`).
  - `gdpm godot uninstall <version>` — Remove installed engine.
  - `gdpm godot list` / `gdpm godot list -r` — List installed or remote versions, with pagination.
  - `gdpm godot add <path>` — Add a local Godot engine (e.g. Steam version), with `--name` alias.
  - `gdpm godot remove <name>` — Remove a local engine.
  - `gdpm godot use <id>` — Set engine for current project (`Name@Version` format).
  - `gdpm godot default <id>` — Set fallback engine; `--unset` clears it.
  - `gdpm godot info` — Show current engine configuration.
  - `gdpm godot open` — Open Godot editor (`--run` runs the project instead).
- **`gdpm config`** — Global configuration from the CLI: `gdpm config set <key> <value>` and `gdpm config open`. Settable keys: `parallel_downloads` (1-32), `default_engine`, `cache_dir`, `language`.
- **`gdpm create`** — Interactive project creation (questionary prompts) with engine selection, template detection, and Godot version compatibility; auto-detects the engine version from `project.godot`.
- **Local plugin management** — `gdpm add --local` packs local plugins into `gdpm-local/` with a `tag.gdpm` marker, hash-based change detection, and rename detection.
- **Global Cache** — Shared cache across projects with split index, `gdpm cache info` / `gdpm cache clean`.
- **Export/Import** — `gdpm export` / `gdpm import` with zip archives; import also accepts a directory.
- **`gdpm info` Redesign** — Rich panel with plugin name, version, description, and install details.
- **`gdpm --about`** — ASCII banner plus version, platform, install type and contributors (replaces the old `-i` flag).
- **Chunked parallel downloads** — Downloads are split into 4 chunks fetched in parallel, each with its own progress bar; overall parallelism is configurable via `gdpm config set parallel_downloads <1-32>` (default 4).
- **`gdpm sync --frozen`** — Lock file sync for CI environments; `--no-cache` to bypass the cache.
- **Shell completion** — `gdpm --completion zsh|bash|fish`, plus completion wired into the install/uninstall scripts.
- **Bilingual installers** — macOS/Linux and Windows install scripts with language selection (follows Windows display language; `-y` skips the prompt).
  - Windows installer runs **in place** and writes **user PATH only** (HKCU): no admin, no UAC, no elevation.
  - Uninstall removes just the PATH entry and marker — user files and `~/.gdpm` are untouched.
- **Help i18n** — Help text follows the configured language (`en` / `zh`), settable via `gdpm config set language`.
- **`-y` / `--yes`** — Global flag to skip confirmation prompts.
- **Loading spinners** — Async network commands show an animated spinner instead of a silent wait.
- **`-V` colored output** — Version display with platform info, styled like uv.

### Installation

```bash
pip install godot-gdpm==0.1.0a1
```

Or download from GitHub Releases:

```bash
# macOS / Linux
tar -xzf gdpm_v0.1.0a1_*.tar.gz
cd gdpm
./install.sh

# Windows
# Extract zip, run install-windows-gdpm.bat
```

### Improvements

- Subcommand help redesigned with Rich panels, usage examples, and a Common Options section.
- `gdpm list` uses a Rich panel with color-coded source prefixes; `gdpm search` output is panel-formatted.
- `gdpm godot add` detects the binary, shows its version, and checks for duplicates.
- `gdpm godot list -id` shows a compact engine-ID view; `godot list -r` paginates remote results.
- Engine binary resolution unified across Windows / Linux / macOS (`.app` bundles included).
- `gdpm init` validates `project.godot` and no longer silently overwrites an existing config.
- `gdpm godot default` is honoured as a fallback when a project has no explicit engine.
- macOS install scripts auto-remove quarantine attributes.
- Hash verification for engine downloads; version normalization (`4.7` → `4.7-stable`).
- Downloads resolve through the mirror rather than guessing platform URLs.
- `GdpmConsole` prints safely on Windows (unencodable characters degrade instead of crashing) and auto-adds spacing to output.
- Version script supports numbered pre-release tags (`beta-2`, `rc3`) and is fully interactive.

### Bug Fixes

- **Path traversal (zip-slip) fixed** when extracting archives — a malicious package could previously write outside the target directory.
- **TLS hardening** — certificate verification and SHA256 checks on the download chain; the last `verify=False` (contributors fetch) has been removed, so certificate verification is back on everywhere.
- Fixed `gdpm godot open` blocking the terminal until Godot exits.
- Fixed `gdpm godot use` crashing on every invocation.
- Fixed cross-platform engine lookup and `gdpm create` engine bugs.
- Fixed `gdpm sync` parallel download passing `zip_path` correctly.
- Fixed `gdpm create` engine version filtering and deduplication.
- Fixed `gdpm list` sorting and folder-name display.
- Fixed `gdpm info` working outside gdpm projects.
- Fixed `gdpm add --local` scan message formatting.
- Fixed cache index path and download destination directory.
- Fixed deprecated `rmtree` onerror and `Popen` context manager usage.
- Fixed `-h` output with consistent blank-line handling.

### Infrastructure

- **Test coverage 43% → 58%** with a **45% gate** enforced in CI; new suites for version/zip/path/platform/installer/add commands.
- **8 CI gates** in one command: `python3 scripts/check.py` runs mypy, ruff, format, pylint, vulture, deptry, pytest, and **zizmor** (GitHub Actions workflow security scan).
- **Release gating** — a `gate` job must pass before binaries are built, so a release can no longer ship downloadable assets while the PyPI publish fails; every job has a timeout (previously a hung job could block for 6 hours).
- **Smoke tests** — `scripts/smoke.py` extracts each archive, runs `--version/--help/--completion`, and on Windows executes a real install → uninstall round trip verifying byte-identical PATH restoration.
- **Coverage reporting** — `scripts/coverage.py` writes a summary into the Actions run page.
- Build script `scripts/build.py` (PyInstaller, 4-platform matrix); `scripts/version.py` manages version bumps across both version files.
- Bilingual issue forms and PR template (modeled on uv's minimal templates).
- License corrected from MIT to **GPL-3.0**; project icon added.
- VS Code workspace and `AGENTS.md` for AI-agent context.

### 新功能

- **仅走镜像的下载通道** —— 引擎二进制与 `versions.json` 全部来自自建镜像，客户端已移除官方 API URL。纯 GitHub 的 worker 通过直连 asset 探测完成版本解析，下载不再受 GitHub API 速率限制影响。
- **Godot 引擎管理** —— 直接通过 CLI 安装、卸载和切换 Godot 引擎版本。
  - `gdpm godot install <版本>` —— 下载并安装（支持 `--csharp` / `-cs`）。
  - `gdpm godot uninstall <版本>` —— 移除已安装的引擎。
  - `gdpm godot list` / `gdpm godot list -r` —— 列出已安装或远程版本，支持分页。
  - `gdpm godot add <路径>` —— 添加本地 Godot 引擎（如 Steam 版本），可用 `--name` 起别名。
  - `gdpm godot remove <名称>` —— 移除本地引擎。
  - `gdpm godot use <id>` —— 为当前项目设置引擎（`Name@Version` 格式）。
  - `gdpm godot default <id>` —— 设置回退引擎；`--unset` 清除。
  - `gdpm godot info` —— 显示当前引擎配置。
  - `gdpm godot open` —— 打开 Godot 编辑器（加 `--run` 则直接运行项目）。
- **`gdpm config`** —— 用 CLI 管理全局配置：`gdpm config set <键> <值>` 与 `gdpm config open`。可设键：`parallel_downloads`（1-32）、`default_engine`、`cache_dir`、`language`。
- **`gdpm create`** —— 交互式创建项目（questionary 提示），包含引擎选择、模板检测与 Godot 版本兼容性检查；可从 `project.godot` 自动识别引擎版本。
- **本地插件管理** —— `gdpm add --local` 将本地插件打包进 `gdpm-local/`，带 `tag.gdpm` 标记、基于哈希的变更检测与重命名检测。
- **全局缓存** —— 跨项目共享缓存，带拆分索引，提供 `gdpm cache info` / `gdpm cache clean`。
- **导出/导入** —— `gdpm export` / `gdpm import` 支持 zip 归档；导入也接受目录。
- **`gdpm info` 重设计** —— 使用 Rich 面板展示插件名称、版本、描述及安装详情。
- **`gdpm --about`** —— ASCII 横幅 + 版本、平台、安装类型与贡献者（取代旧的 `-i` 选项）。
- **分片并行下载** —— 下载切分为 4 个分片并行拉取，各自带进度条；整体并行度可用 `gdpm config set parallel_downloads <1-32>` 配置（默认 4）。
- **`gdpm sync --frozen`** —— 面向 CI 环境的锁定文件同步；`--no-cache` 可绕过缓存。
- **Shell 补全** —— `gdpm --completion zsh|bash|fish`，安装/卸载脚本同样内置补全。
- **双语安装器** —— macOS/Linux 与 Windows 安装脚本支持语言选择（跟随 Windows 显示语言；`-y` 跳过询问）。
  - Windows 安装器**原地安装**，只写**用户 PATH**（HKCU）：无需管理员、无 UAC、无提权。
  - 卸载仅移除 PATH 条目与标记 —— 用户文件与 `~/.gdpm` 一律保留。
- **帮助多语言** —— 帮助文案跟随配置语言（`en` / `zh`），可用 `gdpm config set language` 设置。
- **`-y` / `--yes`** —— 全局跳过确认提示。
- **加载动画** —— 异步网络命令显示旋转动画，不再静默等待。
- **`-V` 彩色输出** —— 版本显示包含平台信息，样式类似 uv。

### 基础设施
